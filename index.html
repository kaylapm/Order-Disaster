BRIEFING KILAT: STANDAR BPMN 2.0

Selamat datang di The Order Disaster! Perbaiki alur proses bisnis yang kacau sesuai aturan resmi BPMN 2.0:

CIRCLE EVENT
START
-
END
Start (○ Tipis) = Pemicu proses dimulai.
End (● Tebal) = Titik akhir saat proses selesai.
BOX TASK (VERB-OBJ)
TASK
Kotak Rounded = Unit kerja aktif berformat Kata Kerja + Objek (contoh: "Input Menu Pesanan", "Panggang Daging Patty").
DIAMOND XOR GATEWAY
✕
Belah Ketupat (✕) = Percabangan keputusan eksklusif: hanya memilih 1 jalur alternatif (contoh: "Metode Bayar Tunai?").
DIAMOND PARALLEL (AND)
+
Belah Ketupat (+) = Percabangan paralel: membuka atau menyatukan beberapa aktivitas serentak (contoh: Dapur memanggang pizza & Kurir menyiapkan armada).
DOUBLE CIRCLE TIMER EVENT
⏱
Lingkaran Ganda (⏱) = Intermediate Timer Event untuk menahan proses hingga durasi waktu terpenuhi (contoh: "Tunggu 15 Menit Oven").
Aturan Penting BPMN 2.0 untuk Tim:
1. Penamaan Task (Verb-Object): Aktivitas harus aktif, 2–4 kata, dan atomik (contoh benar: "Racik Kopi Espresso", bukan "Pengecekan" atau hanya kata benda).
2. Satu Masuk, Satu Keluar: Task tidak boleh bercabang langsung; percabangan wajib memakai Gateway (XOR / Parallel).
3. Penempatan Swimlane: Setiap balok harus berada di Lane aktor yang berhak mengeksekusinya (Pelanggan, Kasir, Koki, Kurir).
